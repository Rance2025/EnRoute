# 顶部导航与导航样式设置设计

## 背景

顶部主导航需要从静态品牌 + 文字分页面入口，调整为更紧凑的滑动式导航。用户最终选择默认使用纯 icon 版，同时保留设置项，允许在纯 icon 和图文混合两种样式之间切换。

这次只调整导航呈现和偏好设置入口，不扩展真实概览页能力。

## 目标

- 顶部导航顺序为：Logo 概览、地图、记账、日程。
- Logo 作为可选段，选中后进入 `overview` 视图。
- 默认导航样式为纯 icon。
- 设置中可切换为图文混合样式。
- 设置入口固定放在左侧时间面板左下角。
- 点击设置入口后打开居中的非全屏弹窗。
- 导航样式偏好持久化到本地，刷新后保持。

## 非目标

- 不实现完整主页或概览数据聚合。
- 不新增远程接口或后端持久化。
- 不改变左侧时间面板在不同页面之间的同构布局策略。
- 不引入新的图标库或图片资源。

## 导航规格

顶部主导航使用现有滑动分段导航的视觉模型，但实现为自定义顶栏，因为 Logo 段和页面段宽度不同。

选项包含：

- `overview`：Logo 段，显示 `在途 EnRoute`，可选中。
- `map`：地图，icon 使用 `MapPinned`。
- `accounting`：记账，icon 使用 `Wallet`。
- `schedule`：日程，icon 使用 `CalendarDays`。

默认样式为 `icon`：页面入口只显示 icon，依赖 `aria-label`、`title` 和按钮可访问名称表达语义。设置切到 `mixed` 时，页面入口显示 icon + 中文文字。Logo 段始终显示文字品牌，不加 icon。

当前 `overview` 和 `schedule` 不展开真实功能。`overview` 显示轻量占位主工作区，`schedule` 显示日程占位工作区，不在本次扩展业务能力。

## 设置入口与弹窗

设置入口渲染在 `TimeContextPanel` 的滚动容器第三行，即左侧时间面板左下角。入口是一个 icon 按钮，使用 `Settings` 图标并带有可访问名称 `打开设置`。

点击后弹出居中对话框：

- 有半透明遮罩，但不是全屏页面。
- 对话框居中，宽度限制在适合桌面的中等尺寸，移动端保持边距。
- 标题为 `设置`。
- 提供 `顶部导航样式` 分段选择：`纯 icon`、`图文混合`。
- 支持关闭按钮、点击遮罩关闭、Escape 关闭。

## 状态与持久化

新增本地导航设置状态：

- 类型：`'icon' | 'mixed'`
- 默认值：`'icon'`
- localStorage key：`enroute:navigation-style`

读取 localStorage 时需要容错：不可用、空值、非法值都回退到 `icon`。写入失败时不影响 UI 当前状态。

## 测试策略

- `App.test.tsx` 覆盖默认纯 icon 导航、Logo 可选、设置弹窗打开、导航样式切换和本地持久化。
- `mapLayout.test.ts` 覆盖设置入口属于共享左侧时间面板结构，且没有为具体 view 写页面专属左栏定位规则。
- 新增导航偏好模块测试，覆盖默认值、合法值、非法值和 storage 异常。
- 完成后运行 `npm test`、`npm run lint`、`npm run build`，并用浏览器验证导航和弹窗。
