# 行政区域缩略图固定画框与纵向滑块优化设计

## 目标

“足迹版图”在国、省、市、区之间切换时保持固定高度。中国缩略图的可见轮廓高度与世界缩略图一致，不因自身较窄而撑高卡片。纵向层级切换继续复用通用 `SegmentedControl`，但视觉恢复为一条连续轨道和一个活动滑块。

## 固定画框

- 画框比例固定为 `32:15`，接近当前世界底图实际边界比例。
- 先读取 `base.getBBox()`，再把边界扩展到 `32:15`。
- 中国边界比画框窄，因此只在左右扩展 viewBox，不增加上下留白；世界边界仅做亚像素级校正。
- SVG 同时使用 `aspect-ratio: 32 / 15`，保证相同容器宽度下所有层级高度完全一致。
- 非法或不可测量边界回退到 `0 15 320 150`，回退比例同样为 `32:15`。

## 纵向滑块

- 轨道容器宽度为 34px，使用一层连续浅色背景和轻边框。
- 四个按钮背景透明，不再分别绘制灰色胶囊。
- 只保留通用组件的一个深绿色 thumb，内缩 3px，使用轻量阴影。
- 国、省、市、区标签继续垂直居中，点击、拖动、键盘和 ARIA 行为不变。

## 验证

- 纯函数测试覆盖世界、中国、过宽边界和非法边界。
- DOM/CSS 契约测试覆盖固定画框比例、同高 viewBox 和单轨道按钮样式。
- 浏览器在 2048×1114 与 1366×768 验证国/省切换不改变卡片高度，地图无遮挡，纵向滑块点击和拖动正常。

## 数据安全

只修改前端几何计算、CSS 和测试。不写入 SQLite，不重建任何瓦片或行政区域预计算数据。
