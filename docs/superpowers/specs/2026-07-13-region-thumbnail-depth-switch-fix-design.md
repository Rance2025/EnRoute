# 区域缩略图与层级切换修正设计

## 背景

区域右栏首版已经完成两张卡片、时间范围联动、四级行政区切换和排行榜，但实际数据下暴露出两个渲染缺陷：

- 省、市、区缩略图均直接使用各自 `z=0` 世界行政区瓦片拼接中国底图。世界尺度的量化和逐区域简化在放大后形成大量内部裂缝，区级还会丢失大块轮廓。
- 主地图切换行政区层级时会先重建无过滤的填充和边界图层，随后才等待摘要状态驱动过滤。摘要请求约需数百毫秒，因此期间会短暂显示该层级的全部行政区。

本设计是对 `2026-07-13-region-panel-redesign-design.md` 的定向修正，不改变排行榜、计数口径、时间范围、地图设置或 SQLite 数据模型。

## 目标

1. 国级继续显示完整世界缩略图。
2. 省、市、区共享同一张完整、无内部裂缝的中国底图轮廓。
3. 世界和中国轮廓保持原始横纵比例，不为铺满缩略图而做非等比拉伸。
4. 当前时间范围内到访的行政区继续按所选层级以强调色覆盖，且不绘制边界线。
5. 四级切换按钮移动到缩略图下方，控件外侧不再显示背景框或内边距框。
6. 切换层级时，主地图绝不短暂显示未到访的全部行政区。

## 缩略图数据设计

### 固定底图

国级底图沿用现有世界缩略图生成路径。

省、市、区不再分别从当前层级的全部要素生成底图，而是共同使用省级 `z=0` 只读 MVT 中所有填充要素的合并轮廓。生成过程为：

1. 解码现有省级世界瓦片，不触发瓦片构建或数据库写入。
2. 合并省级填充几何并投影到固定中国画幅。
3. 裁剪到 SVG viewBox，移除由量化缝隙形成的内部孔洞。
4. 简化为一条可缓存的无边界 SVG path。

该底图只表达中国轮廓，不表达省、市、区边界，因此三个层级返回相同的 `basePath`。

### 投影与画幅

世界和中国画幅都使用单一缩放系数等比例投影到固定 SVG viewBox：先计算横向与纵向可用比例，取较小值进行 `contain`，再把结果居中并保留少量固定留白。禁止分别缩放 X、Y 轴来填满 `320 × 150` 画幅。

底图和到访覆盖必须复用同一套投影参数；前端 SVG 保持 `xMidYMid meet`，CSS 只约束稳定画幅，不再承担几何拉伸。横向或纵向出现自然留白是预期结果。

### 到访覆盖

当前层级的到访区域仍来自摘要统计中的 `visitedRegionIds`。服务端在内存中合并相应的投影几何后再统一简化和输出 `visitedPath`，避免相邻到访区域之间出现量化细缝。若瓦片缺少某个已到访区域，继续使用现有 bounds 回退，保证摘要仍可返回。

缩略图生成保持只读，不修改 `admin_regions`、`admin_region_tiles`、`visual_tiles` 或足迹事实表，也不执行任何重建命令。

## 右栏布局

第一张卡内顺序调整为：

1. 标题与动态计数。
2. 固定比例缩略图。
3. `国 / 省 / 市 / 区` 四级切换。
4. 加载状态提示（仅需要时出现）。

层级控件仍为四列等宽按钮，但容器本身使用透明背景、零内边距和零圆角，不再形成第五层外框。按钮保留各自的可点击面积、选中填充、键盘焦点和按压反馈。

## 主地图无闪烁切换

主地图切换层级时采用创建即过滤的策略：

1. `App` 只在摘要的 `depth` 与当前层级一致时向地图传递到访 ID。
2. 新层级摘要尚未返回时传递空 ID 列表，而不是 `null`；`null` 仍只表示用户明确开启“显示全部行政区”。
3. `MapboxCanvas` 创建新的行政区填充和边界图层时立即写入当前过滤器，不先创建无过滤图层。
4. 后续摘要返回后只更新图层过滤器，不再次重建数据源。

因此切换过程中允许短暂不显示行政区覆盖，但不允许出现全部行政区闪现；底图、相机和当前视口保持不变。

## 失败与降级

- 摘要加载失败时保持空过滤，排行榜显示现有错误状态，不回退为显示全部行政区。
- 固定中国底图源瓦片缺失时，沿用当前层级可用几何的合并轮廓；仍不得触发运行时瓦片构建。
- 到访覆盖无法解析某个区域几何时继续使用 bounds 回退，不阻塞其他区域输出。

## 测试与验证

### 自动化测试

- API：省、市、区共享相同的完整底图 path；底图不包含内部裂缝 path；到访 path 按所选区域合并；摘要查询保持只读。
- 组件：SVG 位于层级控件之前；四个按钮与动态单位继续正常切换。
- Mapbox：层级变化后新建图层从第一帧开始携带空或到访 ID 过滤，不出现无过滤图层。
- App：旧层级摘要不会作为新层级可见 ID 传入地图；新摘要返回后恢复正确 ID。

### 浏览器验证

- 在全部时间范围依次查看国、省、市、区，确认世界/中国底图完整且强调区域合理。
- 对照主地图轮廓检查世界与中国缩略图比例，确认没有明显横向拉宽或纵向压扁。
- 快速往返切换四个层级，确认主地图不闪现全部行政区，也不重置相机。
- 检查层级按钮位于缩略图下方且没有外层框。
- 在桌面与移动视口检查右栏文本、卡片高度和排行榜滚动。
- 检查控制台无错误或警告，并复核地图底部工具条、2D 状态和基础地图样式未回归。

## 非目标

- 不改变行政区数据源、层级范围或统计口径。
- 不新增缩略图交互、标签、边界线或第二个地图实例。
- 不预取四个层级的全部摘要。
- 不修改或重建任何 SQLite 视觉瓦片。
