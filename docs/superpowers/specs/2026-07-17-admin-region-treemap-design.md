# 行政区域指标拼图设计

## 背景与目标

区域页面右侧当前依次展示足迹版图和行政区域排行，下面仍有未被利用的剩余高度。本功能在排行下方增加一块区域拼图，以矩形面积呈现当前指标在各行政区域之间的分布。

拼图不是行政区真实面积图，也不表达地理形状。每个矩形面积只编码当前排行指标值在当前显示范围中的占比：

```text
单块面积占比 = 该行政区当前指标值 / 当前拼图全部正值行政区的指标总和
```

拼图同时服从三个既有上下文：

1. 左侧时间范围决定参与汇总的数据日期。
2. 右侧“国 / 省 / 市 / 区”决定基础行政层级，当前选中区域按本文范围表决定是否展示下一层直接子级。
3. 排行依据“足迹 / 时间 / 距离”决定矩形面积、显示数值和同色阶深浅。

目标是补充一眼可读的整体构成，不把右栏变成缩小版统计页。拼图不增加独立时间轴、筛选器、指标切换或分析操作。

## 非目标

- 不展示柱状图、热力矩阵、旅程时间线或行政区真实形状。
- 不改变足迹版图、排行排序、地图聚焦或左侧时间面板行为。
- 不根据请求重建行政区摘要、行政区瓦片或足迹视觉瓦片。
- 不写入 `data/footprints.sqlite`，不修改 `footprints`、`admin_region_daily_stats`、`admin_region_tiles` 或 `visual_tiles`。
- 不增加移动端适配。当前右栏继续遵循既有桌面布局和移动端隐藏规则。

## 布局位置

拼图作为 `AdminRegionContextPanel` 的第三块玻璃卡片，固定排在足迹版图和区域排行之后。

区域面板本身占满 `right-context-panel__stack` 的可用高度：

```text
右侧导航
└─ 区域信息面板
   ├─ 足迹版图       auto
   ├─ 区域排行       auto
   └─ 区域拼图       minmax(0, 1fr)
```

第三块卡片自然撑满剩余高度。拼图画布随卡片尺寸重新计算，不为不同视口写固定矩形尺寸。右侧整体空间不足时，保持现有右栏溢出策略，不压缩足迹版图和排行到不可读高度。

## 数据口径

### 时间范围

拼图直接使用现有行政区摘要缓存。左侧时间选择变化时，现有流程已经按该范围预取国、省、市、区四级摘要；拼图不发起独立时间请求。

### 指标

拼图与排行共享 `AdminRegionRankingMetric`：

- `footprint` 使用 `footprintCount`。
- `time` 使用 `stayDurationSeconds`。
- `distance` 使用 `travelDistanceMeters`。

只保留当前指标值严格大于零的区域，与排行的过滤口径一致。矩形按指标值降序进入布局；值相同时继续按中文名称、区域 ID 升序稳定排序。

面积使用原始非负值计算，不采用排行柱条已有的最小可见比例。所有正值区域都保留，不截断、不合并为“其他”，也不人为放大小区域。

### 父子关系

现有 `/api/admin-regions/summary` 响应的每条 `regionMetrics` 增加：

```ts
parentRegionId: string | null
```

后端继续只读当前预计算摘要和 `admin_region_tree`。`query_eligible_admin_region_metadata()` 通过 `LEFT JOIN admin_region_tree` 返回直接父级，`format_precomputed_admin_region_metric()` 将其写入响应。国家层级或没有父级的区域返回 `null`。

前端数据源严格校验该字段。四级摘要仍由现有缓存按时间范围和深度预取，不新增按父级查询接口，不增加选择区域后的网络请求。

## 拼图显示范围

拼图范围由当前层级和 `selectedAdminRegion` 共同决定：

| 当前层级 | 未选择区域 | 选择区域后的拼图范围 |
| --- | --- | --- |
| 国 | 当前时间范围内各国 | 选择中国时显示中国直接下属省级行政区；选择其他国家时仍显示各国 |
| 省 | 当前时间范围内全国各省 | 显示所选省直接下属城市 |
| 市 | 当前时间范围内全国各市 | 显示所选市直接下属区县 |
| 区 | 当前时间范围内全部区县 | 选择区县后范围不变 |

选择导致拼图下钻时，“国 / 省 / 市 / 区”按钮保持原层级，不自动跳到下一层。卡片标题负责说明当前范围，例如：

- 省级未选择：`全国各省`
- 省级选择江苏：`江苏各市`
- 市级选择南京：`南京各区县`

国家层级只对中国下钻。实现不依赖名称文本判断：只有选中区域存在已缓存的直接子级且它是中国国家节点时，国家层级才使用省级子集。中国节点兼容当前数据中的 `CN` 及后端已认可的中国区域 ID 形式。

深度切换沿用现有行为并清除区域选择。若时间范围或排行指标变化后，当前选择不再属于有效排行，继续沿用现有逻辑清除选择并恢复基础范围。

## 拼图布局

使用成熟的 squarified treemap 算法计算矩形，实施时引入轻量的 `d3-hierarchy`，不自行实现矩形切分算法。

布局输入为经过正值过滤和稳定排序的扁平区域数组。根节点总值为各区域当前指标值之和。画布尺寸来自 `ResizeObserver`，卡片宽高变化时重新计算坐标。

矩形间保留稳定的小间距，避免相邻同色块粘连。标签按实际矩形尺寸分级：

- 空间充足时显示名称、占比和格式化指标值。
- 中等空间只显示名称。
- 小块不显示文字，但数据和面积仍保留。

每块都保留完整 `aria-label` 和悬停提示，包含区域名、当前指标格式化值和占比。拼图本身是只读可视化，不承担区域选择或继续下钻；区域选择仍由地图和上方排行负责。这样可避免在省级按钮仍选中时，点击子级城市又产生第二层选择语义。

## 配色

面积是主要数值编码，颜色只辅助识别同一个指标的相对权重，不表示行政区域类别或第二种数据。

采用项目现有远山黛、青绿和雾青灰体系。最大值从 `#1d594c` 开始，中段经过 `#4c897b`、`#75a79b`、`#93b4ab`、`#abc8c0`、`#b8d1ca`，长尾收在 `#c5d7d2` 到 `#d3e1dd`，不淡化到接近玻璃白。

颜色根据 `metricValue / maxMetricValue` 落入固定色阶。相同值必须获得相同颜色。切换时间范围或指标后，颜色可随当前相对权重变化，因为它只强化当前面积语义。

深色块使用浅色文字，浅色块使用深色文字，必须满足可读对比。选择父区域导致子级下钻时，父区域通过卡片标题表达，不在子级拼图中伪造选中块。仅在不下钻的状态下，例如区级选择或国家层级选择非中国国家，当前选中且仍在拼图中的区域显示白色内描边和远山黛外描边，不改变原填充色。

## 状态与更新

### 正常更新

- 切换排行依据时复用已加载摘要，立即重新计算面积、标签和色阶。
- 改变左侧时间范围时跟随现有四级摘要加载生命周期更新。
- 改变层级时清除选择，并使用新层级摘要恢复基础范围。
- 选择中国、省或市时，从已缓存的下一层摘要中过滤 `parentRegionId`，不发起新请求。

数据变化采用短交叉淡入，不对大量矩形做复杂路径变形。`prefers-reduced-motion: reduce` 下禁用过渡。

### 加载

当前层级摘要已就绪但下一层摘要仍在加载时，足迹版图和排行保持可用，拼图卡片保留尺寸并显示轻量加载状态，不回退到错误范围。

### 空数据

当前范围没有所选指标正值时，卡片保持占满剩余高度，显示对应空状态：

- `当前范围暂无足迹数据`
- `当前范围暂无时间数据`
- `当前范围暂无距离数据`

不绘制零面积占位块。

### 错误

当前拼图所需深度摘要加载失败时，只在拼图卡片内显示错误和重试入口。重试调用现有 `retryAdminRegionSummary()`，目标深度为拼图实际使用的深度，不影响其他已就绪卡片。

## 组件边界

### `adminRegionTreemap.ts`

纯函数模块，负责：

- 从指标类型选择数值。
- 解析基础范围或直接子级范围。
- 正值过滤与稳定排序。
- 计算总和、占比、色阶索引和可访问文本。
- 将区域数据转换为 `d3-hierarchy` 的布局输入。

该模块不读取 React 状态、不请求网络、不访问 DOM。

### `AdminRegionTreemapCard.tsx`

负责卡片标题、尺寸观测、treemap 布局渲染、标签阈值、提示、加载、空和错误状态。组件接收已解析的显示范围和状态，不自行理解全局页面导航。

### `AdminRegionContextPanel.tsx`

继续负责区域右栏组合，在版图和排行后挂载拼图卡片，并将当前摘要、下一层摘要、时间范围、排行依据和选中区域传入。原有版图和排行组件行为保持不变。

### 摘要数据源与缓存

`AdminRegionMetric` 增加 `parentRegionId`。现有四级缓存键仍为时间范围与深度，不因拼图增加第二套缓存。缓存取消、最近时间范围淘汰和重试逻辑继续复用现有实现。

## 测试与验收

### 后端与数据契约

- 摘要响应为各层级区域返回正确的 `parentRegionId` 或 `null`。
- 父级字段来自只读 `admin_region_tree`，不改变摘要指标、签名或数据库内容。
- 前端数据源接受合法父级字段并拒绝缺失、非字符串且非 `null` 的值。

### 纯函数

- 足迹、时间、距离分别选择正确值。
- 零值区域被排除，所有正值区域保留。
- 面积输入总和严格等于正值指标总和。
- 同值按名称与区域 ID 稳定排序。
- 四级范围表全部覆盖，包括中国国家级特例、其他国家不聚焦和区级选择不变化。
- 色阶起止颜色、同值同色和文字对比规则稳定。

### 组件与页面

- 拼图位于排行之后并占满右栏剩余高度。
- 左侧时间范围、层级、排行依据任一变化都会更新拼图输入。
- 选择江苏时显示江苏直接下属城市，省级按钮仍保持选中。
- 选择非中国国家不改变国家拼图范围。
- 加载、空、错误与重试状态不改变卡片高度。
- 小块隐藏可见文字但保留完整可访问名称和值。
- 拼图不触发地图选择或额外下钻。

### 浏览器验收

在桌面视口验证：

- 足迹版图、排行和拼图在右栏内无重叠，拼图自然填满剩余高度。
- 时间范围、四级按钮和三种排行依据切换后布局与标题正确。
- 地图或排行选择区域后，拼图按规则切换范围。
- 深色与浅色块文字均清晰，小块间距稳定。
- 右栏滚动、地图交互和控制台保持正常。
- 减少动态效果偏好下没有矩形过渡。

## 实施边界

本功能涉及前端区域右栏、摘要响应只读字段和相关测试。它不需要数据迁移、SQLite 备份或重建预计算数据。实施前后均应确认 `visual_tiles` 和 `admin_region_tiles` 未被写入。
