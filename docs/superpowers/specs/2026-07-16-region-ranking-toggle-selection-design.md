# 区域排行榜重复点击取消与选中柱增强设计

## 背景

区域页右侧排行榜目前可以点击排行项并让地图聚焦到对应行政区，但点击已经选中的排行项时只会再次写入同一个 `selectedAdminRegion`，无法取消选择。排行榜默认柱色为 `#3d8f7d`，hover 与选中态又共同使用 `#2c8572`，因此鼠标移开前后和悬停状态之间的差异不足，选中柱不够醒目。

本轮只修正选择状态切换和选中柱颜色，不改变排行数据、地图行政区配色、卡片布局或滚动行为。

## 目标行为

- 第一次点击未选中的排行项时，沿用现有行为：选中该行政区、更新排行选中态，并让地图聚焦到其边界。
- 再次点击当前已选中的排行项时，将 `selectedAdminRegion` 清空。
- 点击另一个排行项时，直接把选择切换到新行政区。
- 取消选择后，地图行政区选中填充层随 `selectedAdminRegion = null` 清除，排行榜移除 `.is-selected` 和 `aria-current="location"`。
- 取消选择不执行新的相机动画，也不恢复默认视角；地图保留用户当前看到的位置和缩放级别。

## 状态与组件边界

选择切换仍由状态所有者 `App` 负责。新增一个窄职责的排行选择处理函数：它通过函数式状态更新比较当前 `regionId` 与本次点击的 `regionId`；相同则返回 `null`，不同则返回本次排行对象。

`AdminRegionContextPanel` 和 `RankingRow` 保持现有接口。排行按钮仍只上报 `onRegionSelect(ranking)`，不在展示组件内复制选择状态或自行推断地图行为。`MapboxCanvas` 继续读取同一个 `selectedAdminRegion`，无需新增取消选择 API。

## 视觉状态

柱体使用三级、互不混淆的颜色：

- 默认：`#3d8f7d`。
- hover：`#2c8572`。
- 选中：`#123f35`，复用项目现有深墨绿强调色。

选中色规则放在 hover 规则之后或使用等价的明确优先级，确保已选中柱在鼠标悬停时仍保持 `#123f35`。名称、排名、数量、行背景、柱高和柱长均保持现状，不通过弱化其他排行项来制造对比。

## 测试与验收

- 在 App 行为测试中先补回归用例：第一次点击后地图和排行都具有选中态；再次点击同一排行后地图选择属性、`.is-selected` 和 `aria-current` 均被移除。
- 保留“点击另一排行会切换选择”的现有状态路径，不引入第二套选中状态。
- 在 CSS 契约测试中先把选中柱预期颜色写为 `#123f35`，同时确认默认柱仍为 `#3d8f7d`、hover 柱仍为 `#2c8572`。
- 按 TDD 顺序观察新增测试因当前行为和颜色失败，再写最小实现使其通过。
- 运行相关 App 测试、组件测试和 CSS 契约测试，再运行 `npm test`、`npm run lint`、`npm run build` 与 `git diff --check`。
- 在桌面视口浏览器实测：点击排行会聚焦并显示深色选中柱；再次点击会清除地图和排行选中态；取消时地图视角不跳回。

## 非目标

- 不修改行政区摘要接口、排行排序、足迹点数量或柱长比例。
- 不修改地图行政区选择填充颜色、边界颜色或聚焦参数。
- 不修改排行榜卡片尺寸、行高、滚动条、名称和数字排版。
- 不增加“清除选择”按钮、确认提示或选择历史。
- 不实现或验收手机尺寸布局。
