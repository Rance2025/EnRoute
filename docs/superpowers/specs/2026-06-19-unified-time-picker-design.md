# 统一时间选择控件设计

Date: 2026-06-19

## 背景

共享时间面板已经承担地图、记账和后续日程页面的全局时间上下文。当前 `日 / 周 / 月 / 年` 四个顶层粒度需要共享“标题 + 翻页 + 选择区”的控件节奏，并去掉按日选择标题中类似 `2026年7月 · 本周` 的无意义后缀。`周历 / 月历` 是 `日` 粒度内部的显示方式，不属于顶层粒度切换。

## 目标

- 统一 `日 / 周 / 月 / 年` 的顶层选择区节奏。
- 每个粒度都使用“页标题 + 左右翻页 + 网格选择”的控件。
- 在 `日` 粒度内部保留 `周历 / 月历` 二级开关。
- `周历 / 月历` 切换时复用同一个月日期网格，让当前周行平滑移动到月历对应行。
- 月视图显示某一年的 12 个月，并通过左右翻页切换年份。
- 年视图一页显示 10 年，采用 `2 x 5` 网格，并通过左右翻页切换前后 10 年。
- 日视图标题不再显示 `· 本周` 或 `· 本月` 这类后缀。
- 保持共享时间面板、顶部模式切换、回到当前范围按钮和页面摘要区域的现有职责。

## 非目标

- 不改变地图相机、地图控件、地图样式、拖拽边界或点位渲染逻辑。
- 不改变记账页数据模型、录入方式或统计模型。
- 不实现真实外部数据导入。
- 不把 `全部` 和 `自定义` 强行改成网格选择；它们仍是时间范围摘要和范围预设。

## 控件结构

`周 / 月 / 年` 顶层粒度共享同一个选择器外壳，`日` 粒度使用同样的标题栏节奏，但内部增加日历显示方式切换：

1. 区域标题：保留粒度说明，例如 `按日选择`、`按周聚合`、`按月聚合`、`按年聚合`。
2. 页标题栏：左按钮、居中页标题、右按钮。
3. 选择网格：展示当前页内可选择的日期、周、月份或年份。顶层 `周` 使用周聚合卡片；`日` 内部的 `周历` 使用裁剪后的月日期网格。

翻页按钮只改变当前粒度的可见页，不切换到其他粒度。点击网格项才更新实际选中的时间范围。

## 粒度行为

### 日

日视图保留日历语义，并在区域标题右侧显示 `周历 / 月历` 二级开关。标题显示当前月份，例如 `2026年6月`。

`周历` 是默认显示方式，只显示星期标题和当前周的一行日期；左右翻页按周移动。`月历` 展示完整可见月份日期网格；左右翻页按月移动。两种显示方式复用同一个月日期网格，通过容器高度和日期网格纵向位移完成展开、收起动画，日期数字节点不重新挂载。

日视图不再显示 `2026年6月 · 本周` 或 `2026年6月 · 本月`。

### 周

周视图是顶层聚合粒度。标题显示当前月份，例如 `2026年6月`。左右翻页切换上一个月或下一个月。下方显示该月覆盖到的周聚合卡片，例如 `第25周`，并展示对应的日期范围。

点击某个周卡片后，选择范围变为该周的周一到周日。顶层 `周` 不显示 `周历 / 月历` 二级开关，也不复用 `日` 粒度的日期按钮。

### 月

月视图标题显示年份，例如 `2026年`。左右翻页切换上一年或下一年。下方固定显示 12 个月，采用 6 列 2 行或在窄空间下自动收敛为更少列，但保持 12 个选项完整可见。

点击月份后，选择范围变为该月第一天到最后一天。

### 年

年视图标题显示 10 年区间，例如 `2020 - 2029`。左右翻页切换上一组或下一组 10 年。下方固定显示 10 年，采用 `2 x 5` 网格。

点击年份后，选择范围变为该年 `1月1日 - 12月31日`。

## 数据和组件边界

`src/time/timeRange.ts` 继续作为时间选择模型的来源。它需要提供可测试的纯函数来计算：

- 日页标题和可见日期。
- 周页标题、当前月日期网格、当前周所在行索引和可见行数。
- 月页标题和 12 个月选项。
- 年页标题和当前 10 年页选项。
- 各粒度的上一页、下一页翻页结果。

`src/components/TimeContextPanel.tsx` 负责渲染共享选择器外壳，并根据当前 `selection.mode` 映射到对应网格。组件不直接内联复杂日期计算。

样式继续放在 `src/App.css`，沿用现有时间面板的深绿色强调色、浅色内容卡片和圆角按钮体系。网格尺寸需要固定，避免 hover、高亮、标签长度或翻页后导致布局跳动。

## 测试要求

实现前先补失败测试：

- `getCalendarLabel` 或新的日页标题函数不再返回 `· 本周`、`· 本月` 后缀。
- 月视图返回某一年的 12 个月，并且翻页到下一年后标题和选项年份同步更新。
- 年视图返回 10 年一页，标题显示区间，并且网格可按 `2 x 5` 结构渲染。
- 周视图返回周聚合卡片，包含 `第N周` 和日期范围。
- `TimeContextPanel` 在顶层 `周 / 月 / 年` 下渲染页标题栏和聚合网格。
- `TimeContextPanel` 在 `日` 粒度内部显示 `周历 / 月历`，复用同一组日期按钮，并用容器高度和网格位移完成展开、收起动画。

完成后至少运行：

```powershell
npm test -- --run
npm run lint
npm run build
```

因为这是视觉和交互改动，还需要用浏览器检查地图页和记账页的共享时间面板，确认控件不溢出、不遮挡、不造成页面整体滚动。
