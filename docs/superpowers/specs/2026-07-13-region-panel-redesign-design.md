# 区域页右侧栏重设计说明

## 目标

重设计地图“区域”分区的右侧信息栏，使它从通用说明面板变成可浏览、可比较、可导航的区域数据面板，同时把显示范围、足迹点和行政区边界线开关移到各自合适的设置入口。

本次只调整地图“区域”分区。足迹页、统计页、左侧时间面板及其他导航页的右侧栏不进入本次重设计。

## 已确认的产品行为

### 右侧第一张卡：足迹版图

第一张卡标题为“足迹版图”，采用固定画幅的极轻量缩略图。它不是第二个 Mapbox 地图实例，不支持拖拽、缩放、点击、地名或地图控件。

缩略图规则：

- “国”层级显示世界平面缩略图。
- “省”“市”“区”层级显示中国平面缩略图。
- 全部行政区使用低对比灰色填充。
- 当前左侧时间范围内存在足迹的行政区使用主题强调色填充。
- 缩略图不显示行政区边界线。
- 时间范围或层级变化后，缩略图同步更新。

卡内保留一行层级切换按钮，文案固定为“国 / 省 / 市 / 区”。层级切换同时控制主地图、缩略图、计数和排行榜。

计数使用“分子 / 分母 + 动态单位”的紧凑表达，并显示对应比例条。分子是当前时间范围内到访的区域数，分母是当前层级全部可用行政区数。单位和排行榜标题随层级变化：

| 层级按钮 | 计数单位 | 排行榜标题 |
| --- | --- | --- |
| 国 | 国家 | 国家足迹排行 |
| 省 | 省级行政区 | 省级足迹排行 |
| 市 | 城市 | 城市足迹排行 |
| 区 | 区县 | 区县足迹排行 |

例如市级显示“86 / 333 城市”，不能在其他层级继续固定显示“城市”。

### 右侧第二张卡：区域足迹排行

第二张卡按当前层级使用上表中的动态标题，并以“按足迹点”作为排序口径提示。

排行规则：

- 只列出当前左侧时间范围内足迹点数量大于零的行政区。
- 按足迹点数量降序排列；数量相同时按名称、区域 ID 稳定排序。
- 排名是简单序号 `1..N`。
- 卡片可视区高度严格容纳五条完整记录。
- 超过五条时仅列表区域内部滚动，卡片自身高度不继续增长。
- 每条记录展示排名、区域名称、足迹点数量和相对长度条。
- 点击记录后，主地图缩放到对应行政区并强化该区域填充。
- 点击排行不打开新的详情页。

排行榜选择反馈使用独立的选中填充层，不依赖普通行政区边界线。因此关闭区域边界线后，排行点击仍有明确的地图反馈。

### 设置位置与默认值

右侧栏不再显示“仅显示当前时间有足迹的区域”开关。

“设置 > 地图”新增：

- “显示全部行政区”，默认关闭。关闭时主地图只显示当前时间范围内有足迹的行政区；打开时主地图显示当前层级的全部行政区。
- “在区域页显示足迹点”，默认关闭。它只影响“区域”分区；“足迹”分区始终正常显示足迹点。

以上设置使用本地持久化偏好。刷新页面后恢复用户上次选择，但首次使用严格采用上述默认值。

地图底部配置弹层新增“显示区域边界线”，默认开启，只控制项目业务行政区图层的轮廓线。现有“显示行政边界”改名为“显示底图行政边界”，继续只控制 Mapbox 底图自带的行政边界。两个开关必须保持独立。

“显示全部行政区”只改变主地图的行政区过滤方式。无论该设置是否开启，足迹版图、计数和排行榜始终表达当前时间范围内实际有足迹的区域。

## 视觉结构

区域右侧栏继续沿用现有青瓷灰玻璃质感、圆角、字重和间距体系，不改变全局右栏宽度，也不改左侧时间面板的共享几何规则。

第一张卡的信息顺序为：

1. 标题与当前层级提示。
2. 固定比例的轻量缩略图。
3. 动态区域计数。
4. 覆盖比例条。
5. “国 / 省 / 市 / 区”单行分段控制。

第二张卡的信息顺序为：

1. 动态排行榜标题与“按足迹点”提示。
2. 固定五行高的滚动列表。

两张卡不嵌套其他卡片。加载、空数据和错误状态必须保持卡片尺寸稳定，不能引起地图可视区或右栏抖动。

## 前端结构

新增聚焦区域页右栏职责的组件边界：

- `AdminRegionContextPanel`：组合两张区域卡，接收时间范围、层级和排行点击回调。
- `AdminRegionAtlasCard`：渲染极简 SVG 缩略图、动态计数、比例条和层级切换。
- `AdminRegionRankingCard`：渲染固定五行高的完整排行榜并处理选择事件。
- `adminRegionSummaryDataSource`：构造摘要 URL、校验响应并支持请求取消。

`App` 继续拥有跨右栏、设置和地图共享的产品状态：

- `adminRegionDepth`
- `showAllAdminRegions`
- `showFootprintsInRegionMode`
- `adminRegionLinesVisible`
- 当前选中的排行区域 ID

区域摘要只在地图“区域”分区激活时请求。切换时间或层级时取消旧请求，避免慢响应覆盖新状态。刷新期间保留上一次成功数据并显示轻量加载反馈；第一次请求失败时显示紧凑错误和重试入口。

其他地图二级分区继续使用现有右栏内容，不把区域卡推广成全局通用卡。

## 只读摘要接口

新增只读接口：

```text
GET /api/admin-regions/summary?depth=3&range=custom&start=2026-01-01&end=2026-07-13
```

时间参数沿用现有足迹指标和活跃行政区接口的规范化逻辑。`depth` 仅接受 `1..4`。

响应示例：

```json
{
  "depth": 3,
  "visitedRegionIds": ["310100", "330100"],
  "visitedCount": 2,
  "totalCount": 333,
  "thumbnail": {
    "viewBox": "0 0 320 150",
    "basePath": "M...Z",
    "visitedPath": "M...Z"
  },
  "rankings": [
    {
      "rank": 1,
      "regionId": "310100",
      "name": "上海市",
      "footprintCount": 8426,
      "bounds": {
        "west": 120.8,
        "south": 30.6,
        "east": 122.2,
        "north": 31.9
      }
    }
  ]
}
```

接口只读取 `footprints`、`admin_regions` 和 `admin_region_tree`：

- 使用单次集合查询把足迹的最细 `region_id` 归并到指定层级祖先。
- 不逐条足迹调用 Python 祖先查询。
- 不返回原始足迹点。
- 不返回完整 GeoJSON。
- 不写 SQLite，不清理或重建 `visual_tiles`、`admin_region_tiles`。

缩略图使用与主地图同源的 `admin_regions.geometry`，但服务端按固定世界/中国画幅投影、简化并量化成两个紧凑 SVG path：一个灰色底图 path、一个本期到访 path。前端只渲染两个 `<path>`，不创建第二个地图实例。SVG path 按层级和数据版本缓存；时间变化只重新组合本期到访 path。

国家层级分母沿用当前世界国家范围并排除南极洲。省、市、区层级分母沿用当前中国 level 2、3、4 数据范围，不扩展到本规格之外的全球深层行政区。

现有 `/api/admin-regions/active` 可以在兼容期保留，但区域页主路径改用摘要响应中的 `visitedRegionIds`，避免同一时间和层级重复请求活跃区域列表。

## 主地图联动

主地图行政区图层继续读取预计算 MVT。摘要接口只提供过滤、统计、缩略图和聚焦元数据，不取代 MVT 渲染。

- `showAllAdminRegions=false` 时，填充层和普通边界层使用 `visitedRegionIds` 过滤。
- `showAllAdminRegions=true` 时，普通填充层和边界层显示当前层级全部要素。
- `adminRegionLinesVisible=false` 时，只隐藏 `admin-regions-line`，不隐藏填充、排行选择反馈或底图边界。
- `showFootprintsInRegionMode=false` 时，在“区域”分区隐藏足迹 circle layer；切回“足迹”分区立即恢复。
- 点击排行时使用响应中的规范化 bounds 执行 `fitBounds`，并用独立选中填充层过滤到目标 `regionId`。
- 切换层级或离开区域分区时清除不再有效的排行选择。

地图样式重载、语言切换和投影切换后，需要重新应用上述三类可见性和过滤状态，不能恢复到 Mapbox 图层默认值。

## 状态与失败处理

- 加载：保持卡片、缩略图和五行排行视口的固定尺寸。
- 空数据：显示 `0 / 总数 + 动态单位`，缩略图只保留灰色底图，排行榜显示“本期暂无足迹”。
- 摘要失败：不影响主地图基础操作；首次失败显示紧凑重试状态，刷新失败保留上一次成功内容。
- 首次摘要失败且“显示全部行政区”关闭时，主地图使用空区域过滤，不能回退为显示全部行政区；用户明确打开“显示全部行政区”后才允许显示完整区域层。
- 过期响应：时间或层级变化时通过 `AbortController` 取消，不允许旧请求覆盖新选择。
- 本地偏好读取或写入失败：沿用当前偏好模块的容错策略，回退到产品默认值且不阻断界面。

## 测试与验证

### 后端契约测试

- `depth=1..4` 的动态总数、动态单位所需层级值和足迹数量归并正确。
- 时间范围会改变到访区域、计数和排行。
- 排行仅包含足迹点数量大于零的区域，并按数量、名称、ID 稳定排序。
- 直接属于目标层级和属于更细后代层级的足迹都会计入正确祖先。
- 空时间范围返回灰色底图、`visitedCount=0` 和空排行。
- 缩略图世界/中国画幅、无边界 path 和强调色 path 数据稳定。
- 摘要查询不修改 `visual_tiles`、`admin_region_tiles` 或任何足迹事实行。

### 前端单元与组件测试

- 第一张卡按层级显示“国家 / 省级行政区 / 城市 / 区县”。
- 层级按钮同步摘要请求和主地图 depth。
- 排行卡可视高度等于五行，更多条目仍全部存在于滚动容器。
- 点击排行回调包含区域 ID 和 bounds。
- “显示全部行政区”和“在区域页显示足迹点”默认关闭并持久化。
- “显示区域边界线”默认开启，且与“显示底图行政边界”互不影响。
- 区域页隐藏足迹点不影响足迹页。
- 时间和层级变化会取消旧摘要请求。
- 加载、空数据和失败状态不改变卡片外部尺寸。

### 地图图层测试

- 摘要 `visitedRegionIds` 正确应用到 fill 和 line filter。
- 显示全部时移除普通区域过滤，但右栏摘要不改变。
- 关闭区域边界时只隐藏自有 line layer。
- 排行选中填充在普通边界关闭时仍可见。
- 样式重载后恢复区域过滤、足迹点可见性、业务边界可见性和选中状态。

### 浏览器验证

- 国层级显示世界缩略图，省/市/区显示中国缩略图。
- 四个层级的单位、分母、排行榜标题和主地图内容同步变化。
- 左侧日、周、月、年、自定义时间切换会同步刷新缩略图和排行。
- 排行卡恰好显示五条，滚动可访问后续条目，点击能聚焦并高亮。
- 两个地图设置默认关闭并可恢复持久状态。
- 底部配置中的底图边界和区域边界可以分别开关。
- 区域页默认不显示足迹点，开启后显示；足迹页不受影响。
- 地图、右栏、底部工具栏无重叠，浏览器控制台无 Mapbox 运行时错误。

提交前仍需执行：

```powershell
npm test
npm run lint
npm run build
```

## 非目标

- 不重设计足迹页或统计页右侧栏。
- 不新增行政区详情页。
- 不新增排行口径切换，当前只按足迹点数量排序。
- 不把缩略图做成可交互地图。
- 不扩展当前行政区数据范围。
- 不重建、清理或迁移任何视觉瓦片表。
