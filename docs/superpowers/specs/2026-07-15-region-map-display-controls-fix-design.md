# 区域地图显示修复设计

## 目标

修复区域缩略图强调色填充的细缝和行政区边界开关在切换层级后失效的问题，并让地图底部配置弹层只展示当前页面有意义的控制项。新增可持久化的区域填充透明度设置。

## 范围

- 区域缩略图强调色 path 使用与填充完全相同的 `0.6` viewBox 单位微描边，配合圆角连接和 `paint-order: stroke fill` 覆盖拼接及抗锯齿细缝。底图 path 不加描边，不修改或重建任何预计算数据。
- 行政区 line layer 每次创建或重建时直接读取当前边界开关状态，不能依赖只在 prop 变化时运行的后续 effect。
- “显示区域边界线”与“区域填充透明度”只在区域页的地图配置弹层中出现。
- 足迹点大小、透明度、颜色和颜色预设只在足迹页出现；区域页仅在“设置 > 地图 > 在区域页显示足迹点”开启时出现；统计页不显示这些足迹样式项。
- 地图形态、地图样式、地图语言、地名和底图行政边界等通用地图设置保持所有地图子页面可见。

## 区域填充透明度

- 默认值沿用当前地图渲染值 `0.18`。
- 范围为 `0.05` 至 `1`，步进为 `0.01`，显示两位以内的规范化数值。
- 使用独立本地偏好键持久化，非法值回退到默认值，越界值截断到合法范围。
- 拖动时只更新 `admin-regions-fill` 的 `fill-opacity` paint property，不重建 Mapbox 实例、source 或 layer。
- level 或样式切换重建行政区图层时，新 fill layer 必须直接使用当前透明度。

## 状态流

`App` 根据当前地图二级页面和“在区域页显示足迹点”偏好，向 `MapboxCanvas` 传递是否展示足迹样式控制的布尔值。`MapboxCanvas` 已有的区域模式状态决定是否展示区域专用控制。

边界可见性和区域透明度都保存在 ref 中。图层创建函数读取 ref 的当前值，因此 level、focus 或 style 导致的重建不会短暂恢复默认值。常规值变化仍通过 Mapbox 的 layout/paint property 原地更新。

## 验证

- 组件测试锁定缩略图只对强调色 path 使用最细同色描边。
- Mapbox 测试复现边界关闭后切换 level，断言重建后的 line layer 仍为 `none`。
- Mapbox 测试覆盖区域透明度的即时更新、持久化、规范化和重建继承。
- 页面测试覆盖足迹页、区域页开关关闭、区域页开关开启和统计页四种配置项组合。
- 完整运行 `npm test`、`npm run lint`、`npm run build`，再在桌面和移动视口检查缩略图细缝、控制项条件展示以及跨 level 状态。

## 数据安全

本次不执行管理区或足迹预计算，不写入 `data/footprints.sqlite`，不修改 `visual_tiles`、`admin_region_tiles` 或任何摘要预计算表。
