# 行政区域缩略图紧凑布局设计

## 目标

压缩“足迹版图”卡片中行政区域缩略图上下的无效空白，并把“国 / 省 / 市 / 区”切换从缩略图下方移到同框右侧独立列，减少卡片高度。

## 已确认布局

- 卡片继续使用一个外框，不增加嵌套卡片。
- 标题行保持不变。
- 标题下方改为一个内容行：左侧为缩略图，右侧为纵向层级切换条。
- 层级切换条不覆盖地图；它占用同一内容行内的独立窄列。
- 复用现有 `SegmentedControl` 的滑块、拖动、键盘和按钮语义，只为通用组件增加纵向方向。

## 缩略图高度

当前 SVG 固定使用 `0 0 320 180`，而 `admin-region-atlas-card__base` 的实际图形边界比画布矮，导致外框参与布局的高度比可见图形多约 30px。

前端在布局阶段读取 base path 的 `getBBox()`，并把 SVG `viewBox` 更新为该实际边界。`useLayoutEffect` 在浏览器绘制前完成更新，避免可见跳动。测量不可用、路径为空或边界非法时，回退到 `0 0 320 180`，保证加载和测试环境稳定。

## 通用纵向分段控件

`SegmentedControl` 新增可选 `orientation`，默认保持 `horizontal`，因此现有调用方不变。纵向模式：

- 以 Y 坐标和容器高度计算拖动位置。
- 滑块按行移动，活动标签按 Y 轴反向平移。
- 增加纵向修饰类和 `aria-orientation="vertical"`。
- 上下方向键、Home、End 沿用现有逻辑；左右方向键继续可用，保持向后兼容。

## 测试与验收

- 单元测试覆盖纵向组件的类名、ARIA、点击、Y 轴拖动和默认横向兼容性。
- 区域面板测试覆盖同框内容行、缩略图动态 viewBox、右侧纵向控件和既有层级回调。
- CSS 契约测试覆盖两列布局、纵向滑块几何和缩略图不再固定 16:9。
- 桌面浏览器在 2048×1114 和 1366×768 验证：地图无遮挡、四级切换可用、卡片高度缩短、下方拼图继续撑满剩余空间。

## 数据安全

本改动只修改前端组件、样式和测试，不读取或写入 SQLite，不重建任何视觉瓦片或行政区域预计算数据。
