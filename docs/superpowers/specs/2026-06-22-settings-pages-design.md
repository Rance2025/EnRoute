# 设置分页与地图统计浮窗配置设计

## 背景

当前设置弹窗只有一个顶部导航样式配置项。用户希望设置弹窗扩展成左侧分页结构，并把地图上的“渲染点数 / 实际点数 / 渲染比例”统计浮窗纳入设置管理，默认不显示。

## 目标

- 设置弹窗保持居中、非全屏。
- 弹窗左侧提供分页导航：通用、地图、记账、日程。
- 通用页保留顶部导航样式配置。
- 地图页新增“显示地图统计浮窗”开关。
- 地图统计浮窗默认隐藏，用户打开后显示，并持久化偏好。
- 记账页、日程页先提供轻量预留状态，不提前实现具体业务配置。

## 非目标

- 不重新设计地图统计浮窗内容。
- 不修改时间面板入口位置。
- 不新增记账或日程业务设置。
- 不做远程 push 或 PR。

## 交互设计

设置弹窗改为双栏结构：

- 左侧为 `通用 / 地图 / 记账 / 日程` 分页按钮。
- 右侧为当前分页内容。
- 默认进入通用页。
- 桌面端左右布局；窄屏可上下排布，保持弹窗非全屏。

通用页：

- 标题为“顶部导航样式”。
- 保留现有 `纯 icon / 图文混合` 分段控件。

地图页：

- 标题为“地图显示”。
- 提供一个开关“显示地图统计浮窗”。
- 默认关闭。
- 打开后，地图右下角当前的统计浮窗显示。
- 关闭后，统计浮窗隐藏。

记账页、日程页：

- 显示简洁预留说明：“暂无可配置项”。

## 数据与持久化

继续使用现有 `navigationPreferences.ts` 承载本地 UI 偏好：

- `enroute:navigation-style`：现有顶部导航样式。
- `enroute:map-debug-panel-visible`：新增地图统计浮窗显示状态。

读取失败、写入失败都应静默回退：

- 地图统计浮窗默认值为 `false`。
- 只有存储值为字符串 `true` 时读取为显示。

## 测试要求

- 偏好读写测试覆盖默认隐藏、读取显示、写入、storage 异常。
- App 测试覆盖设置弹窗四个分页可切换。
- App 测试覆盖地图统计浮窗默认不显示。
- App 测试覆盖在地图分页打开开关后显示统计浮窗并写入 localStorage。
- App 测试覆盖 reload 后恢复地图统计浮窗显示。
- CSS 契约测试覆盖设置弹窗双栏布局和窄屏回退。
