# 左侧面板常驻时间选择器与距离图表设计

## 背景

左侧时间/数据面板继续作为地图、记账、日程等页面的共享左栏。当前地图页在打开时间编辑器时会隐藏下方趋势图，导致默认态下方空间利用不足，编辑态又缺少图表上下文。用户确认采用 A 方案：上半区结构基本不变，时间选择器常驻，下面用距离柱状图补足下半区。

## 设计

1. 上半区保持现有结构：时间范围标题、四个指标区域、时间模式切换仍在同一张左栏卡片中。
2. 四个指标的数字和单位拆开渲染。只有指标数字使用更窄高的数字字体；年份、日期、图表标签、按钮文字等其他数字不跟随变化。
3. 地图页常驻时间选择器，不再通过“修改时间”隐藏或展开。时间操作按钮保留为“回到今天 / 回到本周 / 回到本月 / 回到全部”等快速复位动作。
4. 距离图表常驻在时间选择器下方。图表顶部显示语义上下文，例如“当前范围距离”和“按日汇总 / 17天”；均值数字只显示在图表平均线上。
5. 柱状图使用更高、更细的柱子，顶部仅保留小圆角，不做大胶囊形状。
6. 年视图热力图暂不进入本轮实现。本轮先把日、周、月、自定义范围的统一距离柱状图和常驻选择器做好。

## 范围

本轮只改前端左侧面板表现与测试，不新增真实距离时间序列 API。图表仍使用本地占位序列，后续再接入真实按时间桶聚合数据。
