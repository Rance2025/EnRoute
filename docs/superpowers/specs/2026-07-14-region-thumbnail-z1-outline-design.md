# 区域缩略图 z1 轮廓与自然比例修订设计

## 背景

区域右栏的国、省、市、区切换、排行和主地图无闪烁逻辑已经完成，但真实浏览器验收暴露出两个缩略图问题：

- 世界与中国轮廓都显得横向偏宽。当前投影把一度经度和一度纬度当作等长距离，在中国所在中纬度会造成明显横向拉伸。
- 中国底图读取省级 `z=0` 世界瓦片，并把显示范围裁到北纬 `17°`。源瓦片本来包含海南、台湾和北纬约 `5°` 的南海诸岛，但裁剪与强简化最终只留下少量大轮廓。

用户提供的参考图只作为地理构图和比例基准：大陆、海南、台湾与南海诸岛应在同一连续地图中按真实位置完整显示。缩略图不复制参考图的标签、海洋、描边或底图细节。

## 目标

1. 世界缩略图使用更自然的横纵比例，不再显得扁平。
2. 省、市、区缩略图共享同一张更精细的中国底图。
3. 中国底图完整包含大陆、海南、台湾和南海诸岛，全部按真实地理位置连续显示。
4. 到访区域继续使用强调色无描边填充，并与底图轮廓准确对齐。
5. 缩略图继续只读现有预计算行政区瓦片，不构建、不重算、不写入 SQLite。

## 数据源决策

### 世界

国级缩略图继续读取现有 `admin_region_tiles` 中的：

```text
focus_region_id = world
depth = 1
z/x/y = 0/0/0
```

该瓦片已经包含完整世界国家级几何。世界问题主要来自投影比例，而不是轮廓分辨率，因此不拼接四张 z1 世界瓦片。

### 中国

省、市、区缩略图改读现有中国范围 z1 视觉等价瓦片：

```text
focus_region_id = world
depth = 2/3/4
z/x/y = 1/1/0
```

- 三个层级的 `basePath` 始终由 `depth=2, z/x/y=1/1/0` 生成。
- `visitedPath` 使用当前层级对应的 `depth=2/3/4, z/x/y=1/1/0`。
- z1 省级瓦片包含 34 个省级行政区和南至北纬约 `5°` 的离散几何，直接承接现有全屏地图的视觉等价数据。

读取逻辑必须把瓦片的 `z/x/y` 纳入源描述和缓存键。MVT 局部坐标先结合 `z/x/y` 还原为地理坐标，再进入缩略图投影；不能继续把 z1 局部坐标按 z0 世界坐标解释。

## 投影与画幅

世界和中国都使用带标准纬线修正的等距圆柱投影。横坐标按标准纬线约 `35°` 的余弦修正，纵坐标保持纬度方向，从而纠正当前经纬度等比例换算造成的横向拉宽。

固定画幅从 `320 x 150` 调整为 `320 x 180`，前端对应使用 `16 / 9` 的稳定宽高比。SVG 继续使用 `preserveAspectRatio="xMidYMid meet"`，投影结果在同一画幅内等比居中，不由 CSS 二次拉伸。

显示范围为：

```text
世界：经度 -180° 至 180°，纬度 -58° 至 85°
中国：经度 73° 至 136°，纬度 4° 至 55°
```

中国范围向南扩展到北纬 `4°`，确保 z1 瓦片中的南海诸岛全部落入画幅。所有岛屿保持真实相对位置，不使用角落插图、不平移、不另设插图框。

## 几何处理

1. 只解码 MVT 的填充要素，忽略边界线要素。
2. 对无效多边形先做二维修复，再按行政区合并。
3. 中国底图合并全部省级填充，去除省际共享边和内部孔洞，但保留所有断开的外部多边形组件。
4. 简化发生在投影到 SVG 画幅之后，并使用保拓扑策略；简化不得删除海南、台湾或南海离散组件。
5. 到访区域先按当前层级合并，再输出一个无描边 `visitedPath`，避免相邻到访区之间出现细缝。
6. 输出继续服从现有路径长度上限。z1 省级瓦片的实际复杂度远低于该上限，不需要降级回粗糙的 z0 轮廓。

前端样式保持现有语义：`basePath` 使用浅色填充，`visitedPath` 使用强调色填充，两者都不新增描边。

## 缺失数据与降级

- 若当前层级 z1 瓦片缺失，`visitedPath` 沿用现有原始几何或 bounds 回退。
- 若省级 z1 底图缺失，允许只读回退到省级 z0 瓦片，并使用同一投影、完整中国范围和保组件简化流程。
- 缺失瓦片只表示该预计算结果不可用，不触发 `build_admin_region_tiles`、`DELETE`、`DROP` 或任何数据库写入。
- 摘要接口响应结构保持 `viewBox/basePath/visitedPath` 不变，仅 `viewBox` 的高度从 150 调整为 180。

## 测试设计

### API

- 先写失败测试，证明省、市、区优先读取 `z=1, x=1, y=0`，并把瓦片坐标上下文纳入投影。
- 用包含大陆、海南、台湾和北纬 `17°` 以南离散多边形的合成 z1 瓦片，锁定完整中国范围不会裁掉南海组件。
- 锁定省、市、区返回相同 `basePath`，到访覆盖使用各自 depth 的 z1 几何。
- 锁定世界和中国投影后的轮廓比例处于自然范围，且所有坐标均落在 `320 x 180` 画幅内。
- 锁定 z1 缺失时只读回退，不重建、不写库。

### 前端

- 锁定 SVG `viewBox="0 0 320 180"` 和 `preserveAspectRatio="xMidYMid meet"`。
- 锁定缩略图容器 `aspect-ratio: 16 / 9`，层级按钮仍位于缩略图下方且外层透明无框。

### 浏览器验收

- 在 `1440 x 900` 和 `390 x 844` 下分别查看国、省、市、区。
- 世界轮廓不横向压扁；中国大陆比例接近用户参考图。
- 中国缩略图可辨认大陆、海南、台湾及向南连续分布的南海诸岛，没有角落插图。
- 省、市、区底图轮廓完全一致，到访填充随层级和时间范围变化。
- 排行仍最多显示五行并可滚动，文字和控件不重叠。
- 快速切级仍不闪现全部行政区，也不重置主地图相机。

## 非目标

- 不修改行政区瓦片构建算法或预计算数据。
- 不修改主地图行政区边界、世界观或样式。
- 不在缩略图中增加标签、海洋、描边、南海插图框或第二个地图实例。
- 不改变排行、时间范围、设置项或摘要统计口径。
