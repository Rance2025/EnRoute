# 区域足迹排行榜单行布局设计

## 背景

区域页右侧排行榜当前把行政区名称和比例柱状条上下排列。两行结构使单条数据的阅读路径变长，也让各行显得松散。需要把名称、柱状条和足迹点数量收敛到同一行，同时保持排行榜最多显示五条、超过五条可滚动的既有行为。

## 目标

- 每条排行使用单行结构：`排名 | 名称 | 柱状条 | 足迹点数量`。
- 名称列固定预留四个中文字符宽度，使所有柱状条从同一横向位置开始。
- 超过四个中文字符宽度的名称显示省略号，并保留完整名称提示。
- 移除排行项之间的分割线，以行间留白和悬停反馈区分条目。
- 保留比例柱、点击选择、键盘焦点、五行最大高度和超出滚动行为。

## 布局方案

排行按钮继续作为完整行的交互容器，内部使用四列 CSS Grid：

```text
22px | 4em | minmax(0, 1fr) | auto
排名 | 名称 |      柱状条      | 数量
```

- 排名列维持紧凑居中。
- 名称列使用 `4em` 固定轨道；文本设置单行、省略号和 `min-width: 0`。
- 柱状条占据剩余宽度，所有行天然共享相同左侧起点。
- 数量列按内容宽度布局、右对齐，并使用等宽数字。
- 四列内容垂直居中；不通过绝对定位制造柱状条起点。

现有包裹名称和柱状条的两行容器不再承担网格布局。组件可以直接把名称和柱状条渲染为排行按钮的同级子元素，减少不必要的嵌套并让列语义与视觉结构一致。

## 视觉与交互

- 删除排行按钮的 `border-bottom`，不新增替代分割线。
- 保持现有行高和五行视口，避免右栏卡片高度及滚动阈值变化。
- 保留现有轻量悬停背景和键盘焦点反馈。
- 比例柱仍以最高足迹点数量为 `100%`，其余条目按现有比例和最小可见长度计算。
- 被截断的名称通过原生 `title` 提供完整文本；按钮现有 `aria-label` 继续包含完整名称和足迹点数量。

## 测试与验收

- 组件测试验证长名称具有完整 `title`，并保持排行按钮选择行为。
- CSS 布局契约测试验证四列网格包含 `4em` 名称轨道、名称省略规则、比例柱左侧伸展基点，以及排行行没有底部分割线。
- 先运行聚焦测试并确认旧实现失败，再完成最小实现使其通过。
- 完成后运行 `npm test`、`npm run lint` 和 `npm run build`。
- 在桌面视口验证五行排行榜：名称与柱状条同排、所有柱状条左边缘对齐、长名称正确省略、数量右对齐、行间没有分割线、滚动和点击正常。

## 非目标

- 不修改排行数据、排序规则、接口或比例计算。
- 不修改右栏其他卡片、地图图层或行政区层级切换。
- 当前不实现或验收手机尺寸布局。
