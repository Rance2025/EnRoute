# 行政区域纵向分段控件对齐计划

## 目标

修复“足迹版图”卡片中纵向国/省/市/区控件的反色文字错位，并使其视觉材质与左侧时间模式分段控件一致，同时保持现有世界/中国缩略图的固定 `32:15` 画框不变。

## 根因

纵向控件用 `--segmented-padding: 3px` 计算滑块与反色文字层，但容器实际为 `padding: 0`，并额外使用 `1px` 边框。按钮网格与滑块内部网格因此采用不同的可用高度，四行文字中心逐行偏离。

## 实施

1. 在布局契约测试中固定纵向控件的几何与材质要求，并先确认旧实现失败。
2. 让容器真实纵向内边距与滑块计算变量统一为 `2px`，移除边框和旧的绿色轨道底色。
3. 复用时间模式控件的半透明白色轨道、内高光、深绿滑块及灰绿色非激活文字。
4. 运行组件测试、布局测试、lint、build，并在桌面浏览器中测量四行普通文字与反色文字中心，验证点击和拖动。

## 安全边界

仅修改前端 CSS、测试和本计划文档；不读取或写入 SQLite，不重建足迹或行政区域预计算数据。
